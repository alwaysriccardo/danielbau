# Images Directory

Place your images in this directory with the following names:

## Required Images:

1. **hero-hardwood.jpg** - Hero background image featuring interior with hardwood floors as the main attraction
2. **interior-1.jpg** - First interior image for Painting & Decorating services
3. **interior-2.jpg** - Second interior image for Flooring & Facade services  
4. **interior-3.jpg** - Third interior image for Interior Renovation services
5. **interior-4.jpg** - Fourth interior image for Plastering & Insulation services

## Image Specifications:

- **Hero image**: Recommended size: 3840px width (or larger), landscape orientation
- **Service images**: Recommended size: 1600px width, landscape orientation
- **Format**: JPG or WebP (WebP preferred for better compression)

The images will be automatically served from `/images/` path in the application.
